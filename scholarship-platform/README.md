# Genuine Scholars — Responsive Scholarship Platform

Genuine Scholars scholarship discovery website built with HTML, CSS and JavaScript.

Features:
- Responsive public website
- Scholarship directory with dynamic search/filtering
- Scholarship detail pages
- Student/provider registration
- Student dashboard
- Profile editing and completion
- Saved scholarships
- Multi-step applications
- Draft persistence
- Application tracking and timeline
- FAQ/contact/about/how-it-works pages

Run:
Open `index.html` in a browser or serve the folder with a static local server.

Important:
Replace this with a secure backend/API before production use.
